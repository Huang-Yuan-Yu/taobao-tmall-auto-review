✨ 功能亮点
🔁 全自动闭环：待评价列表 → 进入评价页 → AI 写评语 → 好评满星 → 设为公开 → 自动配图 → 提交 → 返回列表 → 下一单，循环到列表清空为止。
🤖 大模型评语文案：调用「兼容 OpenAI 格式」的大模型接口，按商品名称生成具体、口语化、不套模板的真实评价（拒绝"物流快、客服好"这类万能废话）。天猫自动生成「宝贝评价 + 服务评价」两段。
⭐ 一键满星 + 公开：淘宝自动勾选好评并把「描述相符 / 服务态度 / 物流」全部打五星；天猫自动把三组 DSR 打满星；有公开选项时自动设为公开（淘宝选"公开"、天猫取消"匿名"）。
🖼️ 自动配图：抓取商品主图作为评价配图，并按分辨率过滤（最短边 < 400px 的图标/小图一律丢弃），自适应压缩到平台限制内（淘宝 ≤5 张 / 5MB，天猫 ≤3 张 / 500KB）。
🐢 全程强拟人化（防风控核心）：
评语逐字输入（随机键速 + 偶发"思考"停顿），不是瞬间填入；
每一步之间随机等待、进页面先随机滚动浏览；
点击前模拟鼠标移动轨迹 + 滚动到位 + 按下/抬起，而非机械 `.click()`；
每单之间随机间隔；连续评价若干单后自动长休息 1~3 分钟；
检测到验证码/风控自动暂停，等你手动过验证再继续，绝不硬闯。
⏯️ 随时暂停 / 断点续跑：一个按钮两态，暂停后点"开始"从当前步骤继续。
🔗 跨页循环：列表页与评价页是不同子域，循环状态用油猴存储跨域保存，跳转不断档。

🚀 安装
方式一：文件安装（推荐）
安装好 Tampermonkey；
下载本仓库的 `淘宝天猫全自动AI好评.user.js`（或在 GitHub 上打开该文件的 Raw 链接）；
Tampermonkey 会自动识别并弹出安装确认，点击「安装」即可。
方式二：手动粘贴
Tampermonkey 管理面板 → 「+」新建脚本；
清空默认内容，把 `.user.js` 的全部代码粘贴进去；
`Ctrl + S` 保存。
③ 配置 API Key（必做）
安装后，在 Tampermonkey 里打开本脚本代码，找到顶部：
```js
const API_KEY = '';                // ← 在这里粘贴你自己的 Key
const API_URL = 'https://api.chatanywhere.tech/v1/chat/completions'; // 换成你的接口地址
const MODEL_NAME = 'gpt-5.4-mini'; // 换成你的接口支持的模型名
```
> 🔒 **安全提示**：仓库里**不含任何真实 Key**。请填你自己的，且**不要把填好 Key 的版本再上传到公开仓库**，以免被盗刷。

📖 使用方法
打开淘宝「已买到的宝贝」页面（任意订单标签均可）；
页面右侧会出现悬浮控制面板，点击绿色按钮「开始评价」；
脚本会自动跳转到「待评价」标签，然后逐单全自动处理；
想中途停下，点「暂停」即可（当前步骤做完就停，之后可续跑）；
列表评完会提示「🎉 待评价列表已空，循环结束」。
> 若已在「待评价」页，点「开始」会直接逐单评价，不再跳转。

⚙️ 可调参数
打开脚本顶部「🛠️ 用户配置区域」与「🐢 拟人化参数」即可按需调整：
参数	说明	默认值
`API_KEY` / `API_URL` / `MODEL_NAME`	大模型密钥 / 接口地址 / 模型名	需自填
`ENABLE_IMAGE`	是否自动配图	`true`
`IMG_PER_PRODUCT`	期望配图张数（会被平台上限自动收窄）	`6`
`REVIEW_LEN`	宝贝评价目标字数	`80`
`SERVICE_LEN`	天猫服务评价目标字数（上限 100）	`50`
`SET_PUBLIC`	有公开选项时是否设为公开	`true`
`MIN_IMAGE_DIM`	配图最短边阈值(px)，小于此值当图标丢弃	`400`
`HUMAN_MODE`	拟人化总开关（`false` = 极速，不推荐）	`true`
`TYPE_MIN_MS` / `TYPE_MAX_MS`	逐字打字每字随机间隔(ms)	`55 / 165`
`STEP_MIN_MS` / `STEP_MAX_MS`	步骤之间随机等待(ms)	`900 / 2600`
`READ_MIN_MS` / `READ_MAX_MS`	进页面随机"浏览"时间(ms)	`1500 / 4200`
`ORDER_MIN_MS` / `ORDER_MAX_MS`	每单之间随机间隔(ms)	`2500 / 6000`
`BREAK_EVERY_MIN` / `BREAK_EVERY_MAX`	连续多少单后长休息	`4 / 7`
`BREAK_MIN_MS` / `BREAK_MAX_MS`	长休息时长(ms)	`60000 / 180000`
> **仍频繁弹验证码？** 把 `BREAK_EVERY_*` 调小（如 `2 / 3`）、`BREAK_MAX_MS` 调大（如 `300000` = 5 分钟），慢一点会明显更稳。

🧠 关于拟人化与风控
本脚本通过随机化节奏、逐字输入、鼠标轨迹、滚动浏览、长休息等方式尽量模拟真人操作，以降低触发风控的概率。但请注意：
浏览器脚本派发的点击/键盘事件在底层带有 `isTrusted=false` 标记（只有真人硬件事件才为 `true`），这是任何油猴脚本都无法绕过的固有限制；
是否弹验证码还与账号风险画像、网络环境、操作频率等有关。
因此拟人化能显著降低但无法 100% 消除验证码。脚本已内置「遇验证码自动暂停」，此时请你手动完成验证，再点「开始」继续即可。

❓ 常见问题
Q：点"开始"没反应 / 提示配置 API_KEY？
A：请确认已在脚本顶部填入有效的 `API_KEY`，且 `API_URL`、`MODEL_NAME` 与你的接口匹配。
Q：评语生成失败？
A：多为 Key 无效、额度用尽或接口地址不对。面板会显示具体原因，脚本会自动暂停，排查后点"开始"重试。
Q：配图没上传成功？
A：配图依赖抓取商品主图并注入上传控件，个别商品/网络下可能抓不到图——此时脚本会自动跳过配图直接提交，不影响好评。
Q：天猫和淘宝都支持吗？
A：都支持，脚本会自动识别当前评价页属于哪个平台并使用对应逻辑。
